# Config Assistant 使用指南

Config Assistant 是一个基于 Web 的可视化工个，旨在帮助用户快速、准确地为不同游戏配置 AI 击杀检测参数（ROI 区域和颜色阈值）。

## 启动工具

在项目根目录下运行以下命令：

```bash
python main.py config-assistant
```

默认会在浏览器中打开 `http://127.0.0.1:8080`。

### 命令行选项

- `--port`: 指定端口（默认 8080）。
- `--debug`: 开启调试模式。

## 核心功能

### 1. 图片上传与 ROI 选择
- 点击左侧的 **ROI** 按钮（或按键盘 `R` 键）。
- 在上传的视频截图上拖动鼠标来划定检测区域（如右上角的击杀提示框）。
- 可以在左侧列表中重命名 ROI。

### 2. 颜色拾取
- 点击左侧的 **颜色** 按钮（或按键盘 `C` 键）。
- 在图片上点击想要识别的颜色（如击杀提示中的红色文本）。
- 在左侧面板中调整 **容差 (Tolerance)**，实时预览识别出的区域。
- 输入颜色名称（例如 `kill_red`）并保存。

### 3. 配置管理
- 选择现有游戏或输入新游戏名称。
- 点击 **保存配置** 将生成的 YAML 写入 `config/games/` 目录。
- 也可以通过 **下载 YAML** 获取本地副本。

## 快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `R` | 切换到 ROI 工具 |
| `C` | 切换到颜色拾取工具 |
| `Delete` / `Backspace` | 删除选中的 ROI 或颜色 |
| `Esc` | 取消当前操作或清除选中状态 |
| `Ctrl + Z` | 撤销上一步操作 |
| `Ctrl + Y` | 重做 |

## 调试与优化

- **YAML 预览**: 右侧面板会根据当前的选择实时生成对应的 YAML 配置代码。
- **性能**: 工具会自动节流更新频率，确保在大图片上操作依然流畅。
