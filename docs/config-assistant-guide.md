# Config Assistant 使用指南 (v2.0)

Config Assistant 是一个基于 Web 的辅助工具，旨在帮助用户为 FPS 游戏快速录制和生成击杀检测配置。v2.0 引入了全新的“区域优先”交互逻辑。

## 启动方式

在终端中执行以下命令启动 Web 服务器：

```powershell
python main.py config-assistant --port 8080
```

启动后，程序会自动打开浏览器访问 `http://127.0.0.1:8080`。

### 命令行参数
- `--port`: 指定监听端口（默认 8080）。
- `--debug`: 开启 Flask 调试模式。

## v2.0 核心工作流：区域优先 (ROI-First)

在 v2.0 中，所有检测逻辑都绑定在一个基础区域（ROI）之上。

1. **上传截图**: 拖拽游戏截图到主画布。
2. **划定区域**: 在“区域”面板下，在画面中框选击杀流（Killfeed）出现的范围。
3. **配置子逻辑**: 一旦 ROI 确定，即可针对该区域配置 OCR 文字、图标模板或颜色采样。

## 四大功能面板详解

### 1. 区域 (ROI)
- **击杀信息流**: 划定主检测区。系统会自动将其坐标归一化（0.0 - 1.0）。
- **建议**: 框选范围应略大于文字，以兼容不同分辨率或文字长度波动。

### 2. OCR 文字识别
- **实时识别**: 在选定的 ROI 内，系统会自动运行 OCR 并显示识别出的文本及其置信度。
- **关键词匹配**: 设置 `KILL`, `ELIMINATED` 等关键词。系统会根据相似度阈值进行模糊匹配。
- **性能**: v2.0 加入了 OCR 结果缓存，同一截图在同一位置不会重复消耗资源。

### 3. 模板 (Templates)
- **图标捕捉**: 针对难以 OCR 的图标（如击杀小骷髅），可以在 ROI 内截取特定小块作为模板。
- **匹配度**: 设置阈值（0.7-0.9），当实时画面在该位置匹配度超过阈值时触发。

### 4. 颜色 (Colors)
- **吸管工具**: 点击“开启颜色吸管”，在 ROI 内点击目标像素（如血条红色）。
- **实时遮罩**: 右侧面板会显示 HSV 容差预览，直到识别出的高亮区域与你预期一致。

## 快捷键支持

| 快捷键 | 功能 |
| :--- | :--- |
| `1` - `4` | 快速切换：区域、文字、模板、颜色面板 |
| `S` | 直接保存当前配置到 `config/games/` |
| `Escape` | 退出当前操作或关闭模态框 |
| `+` / `-` | 画布缩放 |
| `0` | 重置画布缩放 |

## 文件清理逻辑
- 为保护隐私和节省空间，每次启动 `config-assistant` 时都会自动清理 `temp/uploads` 目录。
- 退出程序（Ctrl+C）时也会触发自动清理逻辑。
